# Dataset Fitur Landing SISMU

Dokumen ini berisi bahan konten untuk landing page SISMU. Formatnya sengaja dibuat per role agar sekolah cepat melihat siapa yang terbantu, fungsi fiturnya apa, dan masalah apa yang selesai.

## Positioning Utama

SISMU adalah platform manajemen sekolah berbasis cloud untuk merapikan data siswa, guru, kelas, presensi QR/RFID, jadwal, tugas, quiz, nilai, rapot, ekstrakurikuler, notifikasi, backup, dan hak akses dalam satu sistem.

Copy pendek untuk hero:

> SISMU membuat administrasi sekolah lebih tertata, cepat, dan profesional.

Masalah utama yang diangkat:

| Masalah | Dampak di Sekolah | Jawaban SISMU |
| --- | --- | --- |
| Data tersebar di Excel, chat, dan file lokal | Data mudah salah versi, sulit dicari, dan rawan hilang | Data siswa, guru, kelas, jadwal, presensi, nilai, dan laporan berada dalam satu platform |
| Rekap presensi lambat | Admin butuh waktu lama membuat laporan harian atau bulanan | Presensi QR/RFID/manual masuk ke sistem dan bisa dicek dari riwayat |
| Informasi terlambat ke wali murid | Wali murid baru tahu setelah masalah menumpuk | Notifikasi dan data kehadiran bisa diarahkan lebih cepat |
| Tahun ajaran baru membingungkan | Jadwal, kelas, siswa naik tingkat, dan arsip lama sering tercampur | Periode akademik, rollover, snapshot, dan keputusan jadwal dibuat lebih terkontrol |
| Akses akun terlalu bebas | Data sensitif rawan dilihat atau diubah pihak yang tidak perlu | Hak akses, role, dan audit membantu mengontrol fitur penting |

## Blok Landing Page yang Disarankan

1. Hero: fokus pada hasil, bukan daftar fitur. Contoh: "Administrasi sekolah lebih tertata, cepat, dan profesional."
2. Masalah: tampilkan 4 pain point utama yaitu data tersebar, presensi lambat, informasi terlambat, data rawan hilang.
3. Fitur utama: tampilkan fitur ringkas dari dataset `landingFeatureCards`.
4. Role benefit: pisahkan manfaat untuk admin sekolah, guru, siswa, dan wali murid.
5. Trust: tampilkan cloud, tenant terpisah, backup, hak akses, audit, dan domain sekolah.
6. Pricing: hubungkan paket dengan fitur yang sekolah paling mudah pahami, seperti QR, RFID, notifikasi, custom domain, dan backup.
