Penggunaan Google

  • Google Sign-In digunakan untuk memverifikasi identitas akun melalui email dan profil Google.
  • Google Drive hanya ditautkan jika admin sekolah memilih menyambungkan penyimpanan Drive.
  • Token OAuth disimpan secara terenkripsi dan dapat dicabut dari akun atau dashboard aplikasi.

Fitur utama

Presensi sekolah

Admin, guru, dan siswa dapat mengelola aktivitas presensi sesuai peran masing-masing.

Manajemen akademik

Data kelas, jadwal, guru, siswa, tugas, quiz, laporan, dan sertifikat dikelola per sekolah.

Integrasi Drive

Admin dapat menautkan Google Drive untuk membantu penyimpanan file dan backup sekolah.
