Privacy Policy

Terakhir diperbarui: 3 Mei 2026

Kebijakan ini menjelaskan cara EduSmart Presensi mengakses, menggunakan, menyimpan, dan melindungi data pengguna, termasuk data yang diperoleh dari Google Sign-In dan integrasi Google Drive.

Data yang kami proses

EduSmart Presensi memproses data yang diperlukan untuk menjalankan layanan sekolah digital, termasuk:

  • Data akun seperti nama, email, foto profil, peran pengguna, dan status akun.
  • Data operasional sekolah seperti kelas, jadwal, presensi, tugas, quiz, laporan, sertifikat, dan pengaturan tenant.
  • Data teknis seperti waktu login, aktivitas sesi, alamat domain tenant, dan log keamanan.

Penggunaan data Google

Jika pengguna memakai Google Sign-In, EduSmart Presensi menggunakan data profil dasar Google untuk proses autentikasi, yaitu nama, alamat email, dan informasi profil yang diberikan Google.

Jika admin sekolah memilih menautkan Google Drive, aplikasi dapat meminta akses Google Drive untuk:

  • Membuat dan mengelola file atau folder yang digunakan oleh EduSmart Presensi.
  • Membaca metadata Drive yang diperlukan untuk menampilkan status sinkronisasi, kuota, dan file yang dikelola aplikasi.
  • Menyimpan informasi akun Google Drive yang tertaut, seperti email, nama, foto profil, folder Drive, token akses, token refresh, scope, dan waktu kedaluwarsa token.

Token OAuth disimpan secara terenkripsi di server dan tidak ditampilkan kepada pengguna lain.

Cara data digunakan

Data digunakan untuk autentikasi, otorisasi akses sesuai peran, pengelolaan data sekolah, pengiriman fitur aplikasi, sinkronisasi Google Drive, audit keamanan, dan dukungan operasional.

Pembagian data

Kami tidak menjual data pengguna. Data dapat diproses oleh penyedia infrastruktur, database, penyimpanan, atau layanan Google yang diperlukan untuk menjalankan fitur aplikasi. Data juga dapat dibagikan jika diwajibkan oleh hukum yang berlaku.

Penyimpanan dan penghapusan

Data disimpan selama akun atau tenant masih menggunakan layanan, atau selama diperlukan untuk kewajiban operasional, keamanan, dan hukum. Admin dapat meminta penghapusan data tenant atau memutus koneksi Google Drive dari dashboard aplikasi.

Kontrol pengguna

Pengguna dapat mencabut akses Google melalui halaman keamanan Akun Google. Setelah akses dicabut, fitur yang bergantung pada Google Drive mungkin tidak dapat digunakan sampai koneksi dibuat ulang.

Keamanan

EduSmart Presensi menggunakan pembatasan akses berdasarkan peran, enkripsi token, validasi sesi, dan pencatatan audit untuk membantu melindungi data pengguna.
